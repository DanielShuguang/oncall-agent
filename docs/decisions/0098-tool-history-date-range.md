# 0098 工具配置变更历史按 UTC 日期范围筛选

## 1. 背景

ADR-0037 的 `GET /admin/tools/{name}/history` 只支持 `limit`（默认 20、最多 100），管理页
的「变更历史」也只能看最近若干条。安全/审计场景经常要回答「上周三谁把这个工具从所有用户
改成仅管理员」，只靠最近 N 条无法定位较早的记录，也无法把一次事件窗口固定下来复核。

工具变更历史本身是长期审计证据：`tool_setting_changes` 只增不改，索引是
`(tool_name, changed_at DESC)`。缺的不是存储，而是按时间范围读取的查询条件。

## 2. 备选方案

| 方案 | 结论 |
|---|---|
| 保持现状，只按 `limit` 取最近 N 条 | 不满足按事件窗口复核；管理员只能反复放大 limit，最多 100 条 |
| 前端对已加载的 20 条做日期过滤 | 会误导：过滤不到未加载的记录，看起来像「没有变更」 |
| 后端增加 UTC 日期范围过滤（本 ADR） | 利用现有索引，无迁移；查询契约清晰 |
| 同时加分页/总数/导出 | 范围更大；分页和导出应在后续 ADR 单独设计 |

## 3. 决策

1. **`ToolSettingStore.history` 增加可选时间窗口**：
   `history(name, *, limit=20, since: datetime | None = None, until: datetime | None = None)`。
   `since`/`until` 是带时区的 UTC 时刻，`[since, until)` 左闭右开；为 `None` 的一侧不限制。
2. **API 用自然日表达**：`GET /admin/tools/{name}/history` 增加
   `changed_from`、`changed_to`（`YYYY-MM-DD`，UTC）。两端必须同时提供；只给一端、
   `changed_from > changed_to` 或闭区间超过 365 天均返回 422 `INVALID_RANGE`。
3. **换算边界**：`since = changed_from 00:00:00Z`，
   `until = changed_to + 1 天 00:00:00Z`，即结束日整天包含在内。API 不接受具体时分秒，
   避免管理员在页面上拼出跨时区的模糊窗口。
4. **查询顺序不变**：仍按 `changed_at DESC, id DESC` 排序，`limit` 仍是 1–100；日期范围
   只是过滤，不改变「最近 N 条」的含义。没有 total / 游标，避免在低写入量的审计表上
   引入第二套分页协议。
5. **内存与 PG 同口径**：内存实现先按 `tool_name` + `since`/`until` 过滤再排序截断；
   PG 查询追加 `changed_at >= since` 与 `changed_at < until`，继续使用
   `idx_tool_setting_changes_tool_time`，不新增迁移。
6. **管理页交互**：历史 Dialog 增加「开始日期（UTC）」「结束日期（UTC）」、「应用」与
   「清除」；只在点击应用后发请求，避免每输入一天就查库。前端预校验「必须同时选择」与
   「开始不能晚于结束」，后端仍是最终权威。应用/清除后立即进入加载态并丢弃旧请求结果，
   防止慢响应覆盖新窗口。
7. **不持久化筛选**：关闭 Dialog 后清空日期，不写 localStorage。历史查询是临时审计动作，
   不是需要跨刷新保留的用户偏好；避免与 ADR-0078 的审计页过滤记忆混淆。

## 4. 后果

- 管理员可以固定一个 UTC 自然日窗口复核工具配置变更，回答「这个窗口里改过什么」；
  不再需要导出整表或在日志里 grep。
- 没有 total 与分页：窗口内超过 100 条时只能看到最近 100 条；历史写入量与管理员操作次数
  同阶，v1 接受。需要完整归档时走后续「工具历史导出」ADR。
- 只支持日期粒度，不支持时分秒；需要精确定位到某一次操作时，仍可按时间倒序看相邻记录。
- 未知工具名仍返回空列表，不返回 404；工具下线/改名后历史仍可查。
- 不改变保留策略与写入逻辑；无迁移，`0025` 保持不变。

## 6. 待定

- 工具历史分页/总数：窗口内超过 100 条时的完整浏览。
- 工具历史 CSV/JSON 导出：与导出下载审计（ADR-0094）同一条链路，需新增资源类型与迁移。
- 查询本身是否要写一条「谁在何时查了哪个窗口」的读取审计；当前只记录配置写入。
- 历史保留期与冷归档：仍与 ADR-0021/0027 的审计保留一起设计。
