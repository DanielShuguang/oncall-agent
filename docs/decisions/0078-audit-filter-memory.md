# ADR-0078：审计页记住用户/会话过滤与统计窗口

- 日期：2026-11-15
- 状态：Accepted

## 背景

ADR-0075 只记住审计页的日期预设。管理员按用户/会话排查后，刷新或第二天再打开仍要从空白
重新填写；统计窗口也每次回到 30 天。交接班和周期性复盘会反复使用同一组过滤，重复输入既慢
又容易漏填。

审计页是管理员只读页，过滤值是普通字符串和 7/30/90 枚举，适合保存在浏览器本地；不需要
服务端表、迁移或跨设备同步。

## 备选

| 方案 | 取舍 |
|---|---|
| 不记忆（现状） | 每次重填，最省事但体验差 |
| URL query 参数 | 可分享、可前进后退；但审计页不是路由驱动，需引入 URL 状态同步，且会把用户 ID 暴露在地址栏 |
| 服务端偏好表 | 可跨设备；需新表、迁移、读写接口与多实例缓存口径 |
| `sessionStorage` | 只保留当前标签页，刷新仍在、关闭即丢；仍不满足“下次打开” |
| `localStorage`（采纳） | 实现小、刷新/重启仍在；按浏览器、不跨设备，接受这一边界 |

## 决策

1. **存储键与内容**：`oncall.audit-filters.v1`，只存 `{ userId, sessionId, statsDays }`；
   不存日期范围（日期预设由 ADR-0075 独立记忆）、不存列表游标/导出状态。
2. **读取校验**：`userId`/`sessionId` 去空白且长度不超过 64；`statsDays` 只接受 7/30/90，
   非法/缺省按 30。对象非法、JSON 解析失败、存储不可用时返回空记忆，不影响页面。
3. **首屏恢复**：`AuditPage` 首次渲染时同时读取日期预设与过滤记忆；把用户/会话写入过滤
   条件、输入框和统计窗口，避免先按空过滤请求一帧再跳变。用户/会话过滤与日期预设可叠加。
4. **写入时机**：点击「筛选」且校验通过后写入当前已应用的用户/会话与 `statsDays`；
   切换统计窗口时写入；草稿输入未点筛选时不写。
5. **清除与默认值**：点击「清除」删除记忆，并把当前统计窗口恢复为默认 30 天；三项都是
   空/30 时也删除键，不保留无意义状态。存储异常一律静默，筛选、统计、导出继续工作。
6. **范围**：不做跨设备同步、不做服务端偏好、不记导出的过滤快照、不记日期范围；
   日期预设仍由 ADR-0075 单独保存。无后端/迁移。

## 后果

- 打开审计页会自动套用上次的用户/会话过滤与统计窗口；过滤卡片和输入框可见，管理员能看出
  当前不是全量视图。
- 如果上次的用户/会话已不存在或无权访问，会得到空列表；清除过滤即可恢复。
- 同一浏览器多个管理员共用同一 profile 时会看到彼此上次的过滤值；这是本地偏好的固有权衡。
- 自定义日期范围生效时统计窗口被隐藏，但记住的 7/30/90 仍保留，清除日期范围后继续使用。
- 点「清除」会同时把当前统计窗口恢复为默认 30 天，避免当前窗口与下次打开记住的窗口不一致。

## 待定
