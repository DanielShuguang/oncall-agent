# ADR-0127：审批统计窗口按浏览器记住

## 背景

审批中心的积压/等待统计提供 7/30/90 天窗口（ADR-0048/0050）。开关与刷新间隔已由 ADR-0122/0123 记住，但统计窗口每次打开都回到 7 天；固定看 30/90 天的值班管理员每次都要手动切。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 并入 `oncall.approval-stats-auto-refresh.v1` | 不采纳：该 key 只表达开关，混入窗口会让「是否自动刷新」与「看多长窗口」互相耦合。 |
| 复用审计页的统计窗口 key | 不采纳：跨页共用会让审批页与审计页互相覆盖。 |
| 独立 key，只接受 7/30/90 | 采纳：默认 7；缺失/损坏/越界回退 7；与列表状态、过滤器无关。 |

## 决策

1. 新增 `oncall.approval-stats-window.v1`，值为 `7`/`30`/`90` 的字符串；默认 7 天不写 key（删除）；写入无效/越界值时按 7 处理并删除 key。
2. `ApprovalsPage` 用 `readApprovalStatsWindow` 懒初始化 `statsDays`；切换窗口时写 key。
3. 切换账号由 `clearLocalPreferences` 清该 key，避免下一位用户继承上一位的统计视角。
4. 与列表状态、待办/已办切换、工具/审批人/日期筛选无关；不跨设备同步。
5. 不改 API/后端/迁移；只影响统计卡与统计导出的窗口。

## 后果

- 审批统计默认仍是 7 天；管理员切到 30/90 后刷新/重开保持。
- 默认 7 天不产生多余 key；本地偏好不参与权限判断。
- 自动刷新失败、暂停等行为不受窗口偏好影响（ADR-0116/0122）。

## 验证

- `approvalStatsWindow.test.ts` 3 用例：默认/非法回退、写 30/7/45 的删除语义、存储异常静默。
- `localPreferences.test.ts` 断言切换账号清 key。
- 前端 `tsc`、`oxlint 0`、`vitest`、`oxfmt --check`、`pnpm build` 通过。

## 待定
