# ADR-0040：会话重命名

- 状态：已采纳（W6 后补）
- 日期：2026-11-12

## 背景

会话是 `runs.session_id` 的投影：标题取最早一条非空 `input`（ADR-0030），列表有
keyset 分页（ADR-0033）与标题搜索（ADR-0039）。用户没法给会话起一个更好认的名字：
问过「打印机离线」的会话，过两天只想从侧栏找「A 楼 3 层打印」。

不能改 `runs.input`：用户原话是进入事件表的证据，事件只增不改（R1），run 的
`input` 也是保留清理与审计的对象。也不能把标题放浏览器 `localStorage`：多设备、
清缓存、换浏览器都会丢，而且会话列表本身以服务端为准。新建一张 `sessions` 表则要
回填历史 run、维护会话生命周期，收益不足以抵消复杂度。

## 备选方案

| 方案 | 否决原因 |
|---|---|
| 改 `runs.input`（最早一条） | 破坏用户原话证据；改历史数据违反只增不改 |
| 前端 `localStorage` | 多设备不一致；清缓存即丢；与服务端投影原则冲突 |
| 新建 `sessions` 表并回填 | 需要迁移历史 run、定义生命周期与清理；只为存一个显示名 |
| **旁挂 `session_titles` 表（采纳）** | 只存用户改过的标题；没有会话时不产生行；不碰 runs/事件 |

## 决策

1. 新增 `session_titles`：`(user_id, session_id)` 复合主键、`title`（最多 60 字符）、
   `updated_at`。没有外键——会话不是实体，没有独立的创建/删除时机；不加额外索引，
   主键足够点查。迁移 `0016`。
2. 显示标题 = 自定义标题；没有则回退到最早一条非空 `input`；都没有则为 `null`
   （前端显示「无标题」，会话仍保留）。自定义标题不参与 60 字符截断：
   接口就限制 1–60，超过直接 422，不悄悄截断。
3. 搜索同时匹配**自定义标题**与**首条问题**。改名后旧关键词仍能找到这个会话，
   避免「刚改完名字，搜新名字可以、搜原来的问题却没了」。
4. `RunStore.rename_session(*, user_id, session_id, title: str | None) -> bool`：
   `None` 清除自定义标题、恢复默认；只有该用户确实有这条会话才返回 `True`，
   否则 `False`（路由翻 404，不区分「别人的」与「不存在」）。
5. `PATCH /api/sessions/{session_id}`：body `{"title": string | null}`。裁掉首尾空白；
   空串 422 `INVALID_TITLE`（要恢复默认请显式传 `null`）；超过 60 字符 422；成功 204；
   库不可用 503。标题格式校验先于归属检查：非法标题对「别人的/不存在的」也返回 422，
   合法标题下才区分 404，避免通过错误码探测会话存在性。
6. 重命名**不写 run 事件**：这是会话列表的显示配置，不是 run 的执行事实。
   `run_count`、`updated_at`、列表排序都不变——排序仍按最近一次 run 活动。
7. 前端侧栏行内编辑：铅笔 → 输入框（`maxLength=60`）+ 保存/取消，Enter 提交、
   Escape 取消；保存成功后按当前搜索词刷新第一页，失败写会话列表错误位。保存中用
   `renameRequest` token 只接受最后一次提交的结果，并禁用保存按钮——避免旧响应关掉
   用户刚打开的另一行编辑器，也避免连点产生两次 PATCH。
8. v1 不做批量改名、置顶/归档、管理员跨用户查看；软移除后来由
   [ADR-0041](0041-session-remove.md) 补上，硬删除仍未做（「删 run 还是只隐藏」留待后续）。

## 后果

- 会话标题与 run 内容解耦；改名不影响任何 run、事件、引用与保留清理。
- 搜索需要同时看标题行与首条 input，Postgres 用 `coalesce` + 两个 `strpos`；
  标题行很小，按主键 join，成本可接受。
- 标题行是旁挂数据：会话的 run 被事件清理后不会自动删除（与会话列表投影一致，
  没有清理任务）；当前没有按用户删数据的入口，属已知边界。
- 并发改名是 last-write-wins，没有版本号；单用户自己改名，冲突概率很低。
- 改名本身不留 who/when 之外的历史（`updated_at` 只有最后时间）；管理员审计视角
  不在 v1 范围。
