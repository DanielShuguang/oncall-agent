# ADR-0066：会话恢复审计统计按过滤

- 状态：已采纳
- 日期：2026-11-14
- 相关：[ADR-0065](0065-session-restore-audit-stats.md)（统计）、
  [ADR-0063](0063-session-restore-audit-console.md)（管理页）、
  [ADR-0064](0064-session-restore-audit-total.md)（列表总数）、
  [ADR-0061](0061-session-restore-audit-session-filter.md)（按会话过滤）

## 1. 背景

ADR-0065 的统计是全局的：管理页无论当前按哪个用户/会话过滤，顶部「恢复活动」
都只给全部用户的汇总。列表、首屏总数和 CSV 导出已经支持 `user_id`/`session_id`，
统计却回答不了「这个用户最近 30 天恢复了多少次」；管理员只能看列表或导出后自己算。

统计接口已经有窗口和聚合，补上与列表相同的两个过滤条件即可，不需要新表、迁移或
新的聚合路径。ADR-0065 的「待定」也把「统计按用户/会话过滤或下钻」列为后续项。

## 2. 备选方案

| 方案 | 取舍 |
|---|---|
| 保持全局，统计下钻用列表/导出 | 无法回答单用户/单会话的窗口规模；管理页三个数字与列表口径不一致；否决 |
| 前端遍历当前已加载页再求和 | 只覆盖已加载页，不是窗口全量；多请求且容易漏；否决 |
| 新增 `/stats/users`、`/stats/sessions` 等独立端点 | 过滤维度会继续增长，端点爆炸；现有端点加参数更直接；否决 |
| 统计只接受 `user_id` 或 `session_id` 之一 | 列表允许组合过滤，统计不能组合会再次口径不一致；否决 |
| 在现有 stats 上加同列表的过滤参数 | 复用查询条件、无迁移、口径一致；采纳 |

## 3. 决策

1. `GET /admin/session-restores/stats` 增加可选 `user_id`/`session_id`，长度
   1–64，与列表参数完全一致；不带参数时保持全局统计（旧客户端不受影响）。
2. 过滤同时作用于汇总（`restores`/`users`/`sessions`）和 `daily`；`users` 是
   过滤后窗口内的去重操作者数。窗口、UTC 日聚合、稀疏不补零的语义不变。
3. 无迁移、无新索引；`user_id` 复用 `(user_id, restored_at)`，`session_id`
   复用迁移 0020 的 JSONB GIN。统计仍是两条查询，不保证与列表同一快照。
4. 前端统计卡跟随「下方已应用」的列表过滤：无过滤时显示「全部用户」，有过滤时
   显示「当前过滤」；改过滤会重新请求统计，旧响应由独立 token 丢弃。
5. 不在响应里重复返回过滤条件；调用方已经知道自己传了什么。不做统计缓存、
   分页、日期范围过滤或按日下钻。
6. 权限仍是管理员只读；统计不引入会话正文、用户目录或跨用户越权读取。

## 4. 后果

- 管理员可以把统计窗口与列表过滤对齐：按用户/会话看首屏总数、统计和导出时，
  三个入口口径一致。
- 过滤变化会多一次统计请求；统计失败仍只显示错误卡，不影响列表/导出。
- 不带过滤时行为与 ADR-0065 相同，旧前端/旧调用方无需修改。
- 统计仍不能按「某一天」下钻；需要看某天明细时仍用列表/导出。
- 统计与列表/导出不是同一快照，并发恢复或保留清理时数字可能略有出入。

## 5. 验证

- 默认 **499 passed + 40 skipped**；真实 Postgres **536 passed + 3 skipped**；
  Postgres + Redis **539 passed**（只加断言，不新增测试函数）。
- `ruff check` / `ruff format --check`（194 files）/ `mypy app`（113 files）通过。
- 前端 `tsc`、**85 tests / 17 files**、`oxlint` 0/0（72 files）、
  `oxfmt --check` 80 files、`pnpm build` 通过。
- 覆盖：store 契约的全局/按用户/按会话/空结果统计；API 的过滤统计、空结果、
  `user_id`/`session_id` 超长 422；前端带过滤的 stats 查询串。
- 无迁移；列表、导出、保留清理与权限路径未改。

## 6. 待定

- 统计的日期范围过滤（`restored_from`/`restored_to`）；
- 从统计卡片下钻到某天/某用户（当前只对齐过滤）；
- 日趋势图/按小时分布；
- 统计缓存或物化；
- 下载审计与统计 CSV 导出。
