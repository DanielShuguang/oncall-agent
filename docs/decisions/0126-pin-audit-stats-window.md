# ADR-0126：置顶审计统计窗口按浏览器记住

## 背景

置顶审计页的统计卡无过滤时提供 7/30/90 天切换（ADR-0087/0089）。日期预设与用户/会话/动作过滤已分别由 ADR-0118/ADR-0119 记住，但统计窗口每次打开都回到 30 天；管理员固定看 90 天时每次都要手动切。

## 备选方案

| 方案 | 取舍 |
|---|---|
| 并入 `oncall.pin-audit-filters.v1` | 不采纳：ADR-0119 明确该 key 只存非日期过滤，混入窗口会让日期预设/对象过滤/统计窗口三类状态互相耦合。 |
| 复用恢复审计页的统计窗口 | 不采纳：跨页共用会让两页互相覆盖。 |
| 独立 key，只接受 7/30/90 | 采纳：默认 30；缺失/损坏/越界回退 30；与日期范围、过滤无关。 |

## 决策

1. 新增 `oncall.pin-audit-stats-window.v1`，值为 `7`/`30`/`90` 的字符串。默认 30 天时不写 key（删除）。
2. `PinAuditPage` 用 `readPinAuditStatsWindow` 懒初始化 `statsDays`；切换窗口时写 key；「清除」清空并回 30。
3. 切换账号由 `clearLocalPreferences` 清该 key，避免下一位用户继承上一位的统计视角。
4. 日期范围仍优先：有日期范围时统计按范围，7/30/90 按钮隐藏；窗口偏好保留，清范围后恢复。
5. 只记本地、按浏览器，不跨设备；不改 API/后端/迁移。

## 后果

- 置顶审计页的统计窗口在刷新/重开后保持；默认 30 天不产生多余 key。
- 与 ADR-0118/0119 一样，本地偏好不参与权限判断。
- 用户清过滤会同时清日期预设、非日期过滤与统计窗口，符合「清除=回到默认」。

## 验证

- `pinAuditStatsWindow.test.ts` 3 用例：默认/非法回退、写 90/30 删除/清除、存储异常静默。
- `localPreferences.test.ts` 断言切换账号清 key。
