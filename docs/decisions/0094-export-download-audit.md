# ADR-0094：CSV 导出下载审计

- 状态：已采纳
- 日期：2026-11-18
- 相关：ADR-0056（审批列表导出）、ADR-0062（恢复审计导出）、ADR-0068（审批统计导出）、ADR-0070（恢复审计统计导出）、ADR-0084（置顶审计导出）、ADR-0090（置顶统计导出）

## 背景

管理端的 CSV 导出是只读操作，但「谁在什么时候、用什么过滤条件、导出了多少行」本身是治理证据。此前 6 个导出端点都只返回文件，不记录下载行为，ADR-0062/0070/0084/0090 都把下载审计列为待定。随着导出入口增多，仅靠反向代理访问日志无法回答过滤条件和行数，也无法在管理页里按导出人/资源查询。

## 备选方案

| 方案 | 结论 |
|---|---|
| 前端埋点上报 | 不采纳：可被绕过/伪造，不是服务端事实 |
| 反向代理访问日志 | 不采纳：只知道 URL，不知道过滤条件、行数和是否截断 |
| 复用 `run_events` | 不采纳：导出不是 Agent run，混入会破坏事件契约与保留/回放语义 |
| 每个资源各建一张导出审计表 | 不采纳：6 套表/查询/页面，重复且难统一过滤 |
| **统一 `export_audits` 表 + 管理员只读接口** | **采纳**：字段少、可按资源/用户/时间查，后续加保留策略也简单 |

## 决策

1. **新表 `export_audits`（迁移 0023）**：`id`、`user_id`、`resource`、`filters`（JSONB，只存标量过滤条件）、`row_count`、`truncated`、`created_at`。`resource` 用 CHECK 限定为 6 种：`approvals`、`approval_stats`、`session_restores`、`session_restore_stats`、`session_pins`、`session_pin_stats`。`row_count >= 0`。索引 `created_at`、`(user_id, created_at DESC)`、`(resource, created_at DESC)`。
2. **只记录成功生成并即将返回的导出**：CSV 生成后再写入；生成失败不写。`filters` 只保存标量（状态、工具、用户、会话、日期、动作），不保存行内容、工具参数或会话正文。
3. **fail closed**：审计写入失败时导出返回 503 `DATABASE_UNAVAILABLE`，不返回无法留痕的文件。这是有意的取舍：宁可让管理员重试，也不产生「下载了但查不到」的缺口。
4. **6 个导出端点统一接入**：审批列表/审批统计、恢复审计列表/统计、置顶审计列表/统计。列表导出的 `truncated` 来自 5000 行上限；统计导出不截断。统计的 `row_count` 用实际 CSV 行数（去掉表头）。
5. **管理员只读接口** `GET /admin/export-audits`：按 `user_id`、`resource`、UTC 日期范围过滤，`(created_at, id)` 倒序 keyset 分页；游标绑定过滤指纹；首屏返回 `total`，后续页为 null；非法游标 400，日期范围单端/倒置/超 365 天 422，计数/列表失败 503。
6. **前端**新增「导出审计」管理页：用户/资源/日期过滤、20 条/页「加载更多」、首屏总数、行数与截断标识。不做导出文件内容回放，也不新增「再次导出」按钮。
7. **暂不接入 RetentionSweeper**：本次只解决「有没有记录」。导出审计的保留期需要单独讨论（可能比事件更长），当前不删行，避免误删治理证据。

## 后果

- 导出多一次数据库写入；数据库不可用或写入失败时，即使 CSV 已生成也会 503。这是 fail closed 的代价。
- `filters` 是 JSONB，字段由各端点自行组装；新增导出点时必须同时扩展 `EXPORT_RESOURCES`、CHECK 与前端资源下拉，否则写入会 500/约束失败。
- 审计本身只读、不可编辑/删除；当前没有保留清理，表会随导出次数增长，后续需要独立保留策略。
- 不记录下载后的文件是否被打开、复制或转发；它只回答「服务端为谁生成过什么范围的文件」。
- 6 个端点共用 `record_export` 与同一个过滤器清洗规则；统计导出按 CSV 行数计数，与列表的 `row_count` 含义不同（列表是条数，统计是长表行数），文档和前端需分别说明。

## 待定

- `export_audits` 的保留期与清理任务（是否与恢复/置顶审计同为 365 天）。
- 是否提供「导出审计的 CSV 导出」与单条详情；当前只读列表。
- 是否记录下载结果（HTTP 状态/客户端是否收到）；当前以服务端生成成功为准。
- 多副本下的写入顺序不保证与下载完成顺序一致；暂不做客户端确认。
